# Fair-Share API

A REST API for managing shared expenses between friends, roommates, or groups.

The project is being built with FastAPI and PostgreSQL, with the goal of learning backend development through a real-world project.

## Project Status

**In Development**

Current focus:
- User management
- Group management
- Group memberships
- Expense creation
- Multiple payers
- Expense participants
- Equal expense splitting
- PostgreSQL connection pooling
- Database transaction handling
- Database failure handling

---

## Stack

- **Python**
- **FastAPI**
- **PostgreSQL**
- **Psycopg 3**
- **Pydantic**
- **Connection Pooling**
